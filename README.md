# Machine Learning & AI Portfolio

A collection of machine learning, deep learning, data analysis, and AI projects developed using Python.

This portfolio demonstrates my progression from classical machine learning and statistical analysis to deep learning, computer vision, and applied risk modelling.

## Projects

### 01 — Heart Disease Prediction

An end-to-end machine learning classification project focused on predicting the presence of heart disease from patient data.

**Key areas:**
- Data cleaning and preprocessing
- Exploratory data analysis
- Feature analysis
- Classification
- Model evaluation
- Threshold tuning

[View Project](./01-heart-disease-prediction/)

### 02 — Bulldozer Price Prediction

A regression project using historical bulldozer auction data to predict the sale price of heavy equipment.

**Key areas:**
- Data preprocessing
- Feature engineering
- Handling missing values
- Regression modelling
- Model validation
- Predictive analysis

[View Project](./02-bulldozer-price-prediction/)

### 03 — Home Credit Default Risk

A financial risk modelling project based on the Kaggle Home Credit Default Risk competition.

The project explores how machine learning can be applied to predict the probability of loan repayment difficulties using applicant and financial data.

**Key areas:**
- Financial data analysis
- Data cleaning and preprocessing
- Feature engineering
- Classification
- Model evaluation
- Credit risk modelling

[View Project](./03-home-credit-default-risk/)
