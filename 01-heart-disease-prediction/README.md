
# Heart Disease Prediction

## Overview

This project develops a machine learning classification model to predict the presence of heart disease from patient health and clinical characteristics.

The project demonstrates an end-to-end machine learning workflow, from loading and exploring the data through preprocessing, model development, evaluation, and interpretation of results.

This project was completed using Python and is part of my machine learning portfolio.

## Objective

The main objective is to build a classification model that can distinguish between patients with and without heart disease based on available clinical features.

The project focuses on:

- Understanding the structure and quality of the dataset
- Exploring relationships between features and the target variable
- Preparing data for machine learning
- Training a classification model
- Evaluating model performance
- Understanding the strengths and limitations of the resulting model

## Dataset

The project uses a heart disease dataset containing clinical and demographic characteristics of patients.

The dataset is included in this repository:

`data/heart_disease.csv`

The target variable represents whether heart disease is present.

## Machine Learning Workflow

The notebook follows an end-to-end workflow:

1. Importing the required Python libraries
2. Loading the dataset
3. Inspecting the data
4. Performing exploratory data analysis
5. Preparing the features and target
6. Splitting the data into training and testing sets
7. Training a classification model
8. Generating predictions
9. Evaluating model performance
10. Interpreting the results
