# Dog Vision — Dog Breed Image Classification

A deep learning computer vision project focused on classifying images of dogs into their respective breeds.

The project applies deep learning and transfer learning techniques to image data and demonstrates an end-to-end computer vision workflow.

## Objective

The goal of the project is to build a model capable of identifying the breed of a dog from an input image.

## Project Workflow

The project covers the following stages:

1. Loading and exploring the image dataset
2. Preparing and preprocessing images
3. Creating training and validation datasets
4. Building a deep learning model
5. Applying transfer learning
6. Training the model
7. Evaluating model performance
8. Making predictions on unseen images
