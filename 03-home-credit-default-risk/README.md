# Home Credit Default Risk Prediction

This project applies machine learning and data analysis to the problem of predicting loan repayment difficulties.

The project was completed using the Kaggle Home Credit Default Risk competition dataset and submitted to Kaggle.

## Objectives

- Explore financial and applicant data.
- Prepare data for machine learning.
- Engineer relevant features and handle missing values.
- Train and evaluate predictive models.
- Investigate how machine learning can support credit risk assessment.

## Tools and Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Google Colab
- Kaggle

## Dataset

The dataset is available through the [Kaggle Home Credit Default Risk competition](https://www.kaggle.com/competitions/home-credit-default-risk/data).

The original dataset is not included in this repository because of its size and Kaggle's dataset access requirements.
