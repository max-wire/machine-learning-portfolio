
# Bulldozer Price Prediction

## Overview

This project develops a machine learning regression model to predict the sale price of bulldozers using historical auction and equipment information.

The project demonstrates an end-to-end regression workflow involving data exploration, preprocessing, feature engineering, model development, and evaluation.

This project was completed using Python and is part of my machine learning portfolio.

## Objective

The objective is to use historical bulldozer sales data to estimate the sale price of construction equipment.

The project focuses on:

- Understanding a large real-world dataset
- Exploring the characteristics of the data
- Handling missing and categorical information
- Preparing features for machine learning
- Training a regression model
- Evaluating predictions
- Understanding factors that influence model performance

## Dataset

This project uses the **Blue Book for Bulldozers** dataset.

The original dataset is not included in this repository because of its size.

The dataset can be obtained from kaggle and placed locally before running the notebook.

The notebook expects the required dataset files to be available locally.

## Machine Learning Workflow

The notebook follows an end-to-end machine learning workflow:

1. Importing the required Python libraries
2. Loading the historical bulldozer sales data
3. Inspecting the dataset
4. Exploring the data
5. Handling missing values
6. Preparing features for modelling
7. Converting categorical information into a machine-learning-compatible format
8. Splitting the data appropriately
9. Training a regression model
10. Generating predictions
11. Evaluating model performance
12. Analysing the results

## Dataset Size Consideration

The original bulldozer dataset is substantially larger than the datasets used in some introductory machine learning projects.

For this reason, the raw dataset is intentionally **not stored in this GitHub repository**. Keeping large datasets outside the source-code repository makes the project easier to clone and maintain.
